================================================================================
MOBILE VIEW CONSIDERATIONS
================================================================================

RESPONSIVE LAYOUT:
- Stack filters vertically on mobile
- Single map view (tabbed between standard/geological)
- Simplified opportunity matrix (list view instead of scatter)
- Touch-optimized controls
- Downloadable offline map data

KEY FEATURES TO PRESERVE:
- Core filtering functionality
- Map interaction (zoom, pan, click for details)
- Top 10 rankings
- Quick access to valuations

================================================================================
COLOR SCHEME & BRANDING
================================================================================

PRIMARY COLORS:
- Primary: #1E40AF (Professional Blue) - Headers, main actions
- Secondary: #059669 (Success Green) - Positive indicators
- Accent: #DC2626 (Alert Red) - High priority items
- Warning: #F59E0B (Amber) - Medium priority

BACKGROUND:
- Light: #F9FAFB (Off-white)
- Cards: #FFFFFF (White)
- Subtle: #E5E7EB (Light gray borders)

DATA VISUALIZATION:
- Heat Map: Blue (low) → Yellow → Red (high)
- Commodities: Distinct colors per type (Copper=Orange, Gold=Yellow, etc.)
- Status: Green (Active), Gray (Unknown), Red (Inactive)

================================================================================
INTERACTION PATTERNS
================================================================================

MAP INTERACTIONS:
- Hover: Show quick preview tooltip
- Click: Open detailed property card
- Double-click: Zoom to property
- Right-click: Context menu (Add to watchlist, Export, Navigate)

FILTERS:
- Auto-apply (no submit button needed)
- Visual feedback on active filters
- Reset all button
- Save filter presets

DATA TABLES:
- Sortable columns
- Row selection for bulk actions
- Inline expansion for details
- Export selected rows

SLIDERS:
- Real-time map update as slider moves
- Show count of visible sites
- Snap to meaningful increments (10, 25, 50)

================================================================================
PERFORMANCE CONSIDERATIONS
================================================================================

FOR LARGE DATASETS:
- Lazy load map markers (viewport-based)
- Cluster markers when zoomed out
- Cache computed metrics
- Paginate large tables
- Progressive data loading

OPTIMIZATION:
- Debounce slider updates (300ms delay)
- Memoize expensive calculations
- Use WebGL for complex visualizations
- Server-side data aggregation where possible

================================================================================
ACCESSIBILITY
================================================================================

WCAG 2.1 AA COMPLIANCE:
- Keyboard navigation support
- Screen reader compatible
- Sufficient color contrast (4.5:1 minimum)
- Alt text for all visualizations
- Form labels and ARIA attributes

USABILITY:
- Tooltips for complex features
- Help text / info icons
- Consistent interaction patterns
- Error messages with recovery guidance
