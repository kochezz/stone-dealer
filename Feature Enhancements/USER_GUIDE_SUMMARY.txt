## 🎯 Key Highlights

### Density Score Breakdown
```
80-100 (Very High) 🟣 → Priority investigation
60-79  (High)      🔴 → Detailed evaluation  
40-59  (Medium)    🟡 → Secondary priority
20-39  (Low)       🟢 → Monitor
0-19   (Very Low)  🔵 → Low priority
```

### Accessibility Categories
```
80-100 (Excellent) 🟢 → Easy access, low logistics cost
60-79  (Good)      🔵 → Manageable, regular access
40-59  (Fair)      🟡 → Remote, higher costs
0-39   (Poor)      🔴 → Very remote, infrastructure needed
```

### Strategic Quadrants
```
Priority Targets     (High/High)  → ⭐⭐⭐⭐⭐ Acquire NOW
Infrastructure Needed (High/Low)   → ⭐⭐⭐⭐ Plan & Invest
Quick Wins          (Low/High)   → ⭐⭐⭐ Small-scale ops
Low Priority        (Low/Low)    → ⭐ Monitor only
```

## 📋 Quick Reference

### Priority Assessment (30 seconds)
```
1. Check Density Score: >80? ✓
2. Check Access Score: >60? ✓
3. Check Province: Copperbelt/Central? ✓
4. Check Status: Active/Feasibility? ✓
→ If 3+ checkmarks: PRIORITY TARGET
```

### Belt Analysis (2 minutes)
```
1. Select commodity
2. Enable trend lines
3. Note bearing (e.g., 45° NE)
4. Note linearity (>70%? = strong)
5. Identify gaps along trend
→ Gaps = Exploration targets
```

## ✨ Key Takeaways

1. **Density Score** measures resource quality (0-100)
   - 40 pts: Reserve presence
   - 30 pts: Active status
   - 15 pts: Multi-commodity
   - 15 pts: Geological data

2. **Accessibility Score** measures infrastructure (0-100)
   - 40 pts: Distance from base
   - 30 pts: Travel time
   - 20 pts: District development
   - 10 pts: Province infrastructure

3. **Matrix Quadrants** = Strategic priorities
   - Top-right = Best opportunities (develop now)
   - Top-left = Infrastructure investments (plan long-term)
   - Bottom-right = Quick wins (explore/small-scale)
   - Bottom-left = Low priority (monitor only)

4. **Trend Lines** = Exploration guides
   - Direction = Where to look
   - Gaps = Target zones
   - Extensions = Frontier opportunities

5. **Always cross-reference** multiple views
   - No single metric tells the whole story
   - Combine density + access + geology
   - Context matters (regional factors)
