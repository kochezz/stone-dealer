## 🚀 Quick Setup (Choose One Method)

### Option 1: Local Development (5 minutes)

```bash
# 1. Create secrets folder
mkdir .streamlit

# 2. Create secrets file
cat > .streamlit/secrets.toml << 'EOF'
APP_PASSWORD = "Claire&Goska"
EOF

# 3. Run the app
streamlit run app_phase1_enhanced.py
```

**Done!** ✅

---

### Option 2: Streamlit Cloud (3 minutes)

1. **Deploy your app** to Streamlit Cloud from GitHub
2. **Go to Settings** → Click "⚙️" in bottom-right
3. **Click "Secrets"** in left sidebar
4. **Add this**:
   ```toml
   APP_PASSWORD = "Claire&Goska"
   ```
5. **Save** → App auto-restarts

**Done!** ✅

## 🆘 Quick Troubleshooting

**Error: "Password not configured!"**
```bash
# Create secrets file:
mkdir -p .streamlit
echo 'APP_PASSWORD = "Claire&Goska"' > .streamlit/secrets.toml
```

**Git is tracking my secrets!**
```bash
# Remove from git (keep local):
git rm --cached .streamlit/secrets.toml
git commit -m "Remove secrets"
git push

# Change your password immediately!
```

**Wrong password error:**
- Check spelling in secrets.toml
- Remove extra spaces/quotes
- Restart the app
