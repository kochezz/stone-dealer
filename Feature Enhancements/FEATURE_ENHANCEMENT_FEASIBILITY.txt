3. RESERVE VALUATION (LME PRICE INTEGRATION)
--------------------------------------------------------------------------------
REQUEST: "Valuation of probable reserves against current LME prices"

STATUS: ✅ FEASIBLE (Requires reserve quantification first)

CURRENT DATA:
- Reserve data is text-based (needs parsing)
- Commodities are well-defined
- Can calculate potential value once reserves are numeric

IMPLEMENTATION APPROACH:

A. LME PRICE DATA INTEGRATION (2-3 days)
   
   DATA SOURCES:
   
   1. LME OFFICIAL API (Preferred)
      - Real-time pricing for major metals
      - Covers: Copper, Zinc, Nickel, Lead
      - LIMITATION: Subscription required for API access
      - WORKAROUND: Use cached daily prices (manual update)
   
   2. FREE ALTERNATIVE SOURCES:
      - Metals-API.com (Free tier: 50 calls/month)
      - Quandl/NASDAQ Data Link (some free metals data)
      - Web scraping LME website (legal grey area)
   
   3. RECOMMENDED APPROACH:
      - Create a price lookup table (updated weekly/daily)
      - Store in CSV: commodity, price_per_tonne, currency, date
      - Auto-update via scheduled API calls
   
   COVERED COMMODITIES FROM YOUR DATA:
   - Copper ✓ (LME traded)
   - Zinc ✓ (LME traded)
   - Nickel ✓ (LME traded)
   - Iron Ore ✓ (Alternative indices available)
   - Gold ✓ (COMEX/spot prices)
   - Diamond △ (Complex, quality-dependent)
   - Gemstones △ (No standard index)

B. RESERVE QUANTIFICATION (5-7 days)
   
   PARSING STRATEGY:
   
   Step 1: Extract numeric values from text
   - "50 MILLION T" → 50,000,000 tonnes
   - "15% CU" → 15% grade
   - "61% FE" → 61% grade
   
   Step 2: Calculate metal content
   - Total ore × Grade = Contained metal
   - Example: 50M tonnes @ 61% Fe = 30.5M tonnes iron
   
   Step 3: Apply recovery rates (conservative)
   - Copper: 85-90% recovery
   - Iron: 70-80% recovery
   - Gold: 90-95% recovery
   
   Step 4: Handle missing data
   - Use district/geology type averages
   - Apply conservative estimates
   - Flag as "estimated" vs "reported"

C. VALUATION CALCULATION (1-2 days)
   
   FORMULA:
   Estimated Value = Contained Metal × Recovery Rate × Current Price × Discount Factor
   
   DISCOUNT FACTORS:
   - Active mines: 0.8-1.0 (minimal discount)
   - Feasibility stage: 0.4-0.6 (significant uncertainty)
   - Exploration: 0.1-0.3 (high risk)
   - Unknown status: 0.2 (conservative)
   
   FEATURES TO BUILD:
   ✓ Live price ticker on dashboard
   ✓ Valuation per property (USD)
   ✓ Ranking by estimated value
   ✓ Portfolio total value
   ✓ Value density map ($/km²)
   ✓ ROI potential scoring
   ✓ Commodity value breakdown charts
   ✓ Historical price trend impact analysis

D. ADVANCED VALUATION METRICS (Future phase)
   
   NPV CALCULATION:
   - Estimate development costs
   - Project production timeline
   - Apply discount rate (10-15% typical for mining)
   - Calculate Net Present Value
   
   REQUIRES:
   - Operating cost estimates ($/tonne)
   - Capital expenditure estimates
   - Production rate assumptions
   - Mine life projections
   
   RECOMMENDATION: Start with simple valuation, expand later
